# blp — BLP demand estimation and merger simulation

**What this fork is.** This is [jeffgortmaker/pyblp](https://github.com/jeffgortmaker/pyblp) plus my own work for Yale's PhD Empirical IO course (ECON 600, Fall 2025, Prof. Charles Hodgson): `blp.py` (a standalone implementation of random-coefficients logit demand estimation with optimal instruments), the accompanying notebook `blp.ipynb`, and a write-up PDF (`BLP_hw_chadim.pdf`) with diversion ratios and merger counterfactuals. Everything under the original package directories is upstream pyBLP — my contribution is the top-level homework files.

Companion repos: [`dp`](https://github.com/marek-chadim/dp) (single-agent dynamics, Rust 1987), [`dg`](https://github.com/marek-chadim/dg) (BBL dynamic games).
